How it works

It remembers what works.
Not what's true.

Everyone else stores facts. An agent mostly needs something else: which techniques keep working, here, on this codebase, for this problem.
01
An agent finishes a task. Its output is decomposed into claims and candidate patterns.
02
Does this match something already known? If not, it is discarded immediately.
03
Has it surfaced again, in independent work? The same agent repeating itself in one chat does not count.
04
Clear the bar and it is promoted. Being contradicted later demotes it. Nothing is permanent.
The whole idea
A fact is always true and never useful twice.
A lesson is only true here — and only once it has proved itself twice.
